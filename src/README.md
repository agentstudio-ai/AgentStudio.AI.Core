# AgentStudio.AI Core Framework

This package contains the core framework for human-centric AI agent orchestration.

## Contents

- **Templates**: Cognitive thinking patterns and agent templates
- **Workflows**: Pre-defined workflow patterns for agent orchestration
- **Shared Knowledge**: Common knowledge and patterns
- **Agents**: Agent definitions and configurations

## Installation

```bash
dotnet add package AgentStudio.AI.Core
```

## Usage

This package provides the foundational templates and patterns for building AI agents. The actual agent orchestration is handled by the AgentStudio.AI CLI tool.
