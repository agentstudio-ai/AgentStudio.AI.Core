# AgentStudio.AI Core Documentation

This directory contains documentation for the AgentStudio.AI Core framework.

## Documentation Structure

- **API Documentation**: Framework API and usage
- **Templates Guide**: How to use and create templates
- **Workflows Guide**: Workflow patterns and orchestration
- **Agent Development**: Creating and configuring agents
- **Best Practices**: Recommended patterns and approaches

## Getting Started

1. Read the [Templates Guide](templates.md) to understand cognitive patterns
2. Review [Workflow Patterns](workflows.md) for orchestration
3. Follow [Agent Development](agents.md) for creating agents
4. Check [Best Practices](best-practices.md) for recommendations
